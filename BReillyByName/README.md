# BReillyByName

## Overview
This program demonstrates how Java handles internet hostnames using the `InetAddress` class. It shows how a website can be identified by its hostname instead of directly using its IP address.

## How It Works
- The program uses Java's `InetAddress` class from the `java.net` package.
- It takes a hostname as input or uses a predefined hostname.
- Java resolves the hostname into its corresponding IP address.
- The program displays the network address information.

This helps understand how DNS (Domain Name System) connects human-readable website names with IP addresses.

## Concepts Used
- Java Networking
- `InetAddress` class
- Hostname and IP address resolution
- DNS
