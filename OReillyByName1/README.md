# OReillyByName1

## Overview
This program demonstrates how to find the IP address of a website using its hostname in Java. It introduces the basic concept of DNS resolution through Java networking.

## How It Works
- The program uses the `InetAddress` class from the `java.net` package.
- It specifies the hostname of the O'Reilly website.
- Java contacts the DNS system to resolve the hostname into an IP address.
- The resolved network address is displayed on the console.

It shows how Java makes it possible to work with website names without manually knowing their IP addresses.

## Concepts Used
- Java Networking
- `InetAddress` class
- `getByName()` method
- DNS and hostname resolution
