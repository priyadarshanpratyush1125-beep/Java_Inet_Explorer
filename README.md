# JavaInetExplorer ☕

### Exploring Java Networking with Practical Programs

I created this repository to practice Java networking concepts using the `InetAddress` class. Instead of just reading about these concepts, I'm trying to understand them by writing small programs, running them, and checking their outputs.

## What I'm Exploring

- Hostname to IP address resolution
- Working with multiple IP addresses
- Local machine address information
- Comparing network addresses
- Basic Java classes and objects (`toString()`)

## Project Structure

Each program has its own folder containing:
- Java source code
- A separate README explaining the program
- Output screenshots showing the execution
